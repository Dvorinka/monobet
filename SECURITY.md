# Security

MonoBet is a play-money demo app — no real funds, deposits, or withdrawals exist anywhere in the system.

If you find a vulnerability (auth bypass, XSS, injection, privilege escalation, …), please report it privately:

- Email: **info@tdvorak.dev**
- Or open a private [GitHub security advisory](https://github.com/Dvorinka/monobet/security/advisories/new)

Please don't open public issues for security reports. I'll acknowledge and fix as time permits — this is a side project, not a service.
